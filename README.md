# Board preview of the new atotb.org design

**Link:** https://rrcecil.github.io/atotb-preview/

This is an interim preview for the board. It shows the new design and layout with atotb.org's public pages, copied on October 3, 2026 and built from commit 2dd2aae of the private site repository. It isn't the live site, and it isn't the staging site; it's a static copy served by GitHub Pages.

## Switched off in this preview
Every place to give or pay, buy a ticket, register for an event, book a time, sign a petition, join a group or fill in a form is switched off: donation and payment forms and links, sign-up and survey forms, event registration and tickets, booking links, petitions and group invites. Each place says what was switched off ("Donation form switched off in this preview"), and a switched-off link or button stays visible but goes nowhere.

Contact details are hidden: email addresses, phone numbers, payment handles, profile pictures and comments are removed, and each place says "Contact details hidden in this preview".

Maps that carry a map key are switched off too: two with a personal key (a map and a block showing its embed code), and the Jetpack maps, whose shared key GitHub won't accept in a public repository.

## What doesn't work here
- **Search:** the search page explains that search works on the finished site.
- **Topic filters** on the Initiatives page.
- **Trails and trail alerts** aren't in the preview yet.
- **Pages not in the preview** open a "Not in the preview yet" page. Links to PDFs still open atotb.org's files.
- **Speed:** this copy runs on GitHub Pages, so it says nothing about how fast the real site will be.

Videos, maps, charts and social posts stay as atotb.org has them, and load their own services as they do there. Links to other organisations' and government sites stay as they are.

## Privacy
The pages ask search engines not to index them. GitHub Pages logs visitors' IP addresses for security, as GitHub's documentation says.
